# mini-RAG

This is an example application that I want to put into production. It uses the RAG technology trend

---

# Requirements

- python >= 3.13

install python via uv

1. first install uv from [here](https://docs.astral.sh/uv/getting-started/installation/)
2. initialize uv in an empty directory
```bash
cd . mini-rag
uv pyton install 3.13
```

3. activate the environment
```bash
uv init
```
